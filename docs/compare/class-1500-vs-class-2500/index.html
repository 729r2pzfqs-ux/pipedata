Class 1500 vs Class 2500 Flanges

The top two classes in ASME B16.5 — and the size limit that decides between them more often than pressure does.

Short answer. Class 2500 holds 6170 psig at 100 °F against Class 1500's 3705, a factor of 1.67. The catch is size: B16.5 publishes Class 2500 only through NPS 12, so above that diameter Class 1500 is the highest class available and higher pressures need a different standard.

What the class number means

A flange class is not a pressure. It is a rating series: the pressure a flange in that class may hold depends on the material group and the metal temperature, and it is read out of ASME B16.5 Table 2. The class number happens to equal the approximate working pressure in psig for Group 1.1 carbon steel at about 500 °F, which is where the numbers came from historically — but treating Class 1500 as “1500 psi” is wrong at every other temperature.

At ambient, Group 1.1 carbon steel is rated 3705 psig in Class 1500 and 6170 psig in Class 2500 — a factor of 1.67. That ratio holds approximately across the temperature range, because every class in a group is derived from the same allowable stress curve.

The flange gets bigger, thicker and more heavily bolted

Moving from Class 1500 to Class 2500 grows the flange outside diameter by about 13% and the thickness by about 36% on average across the 14 shared sizes. The bolt count rises in 0 of those sizes and the bolt diameter in 11. None of that is free: the flange costs more, the gasket costs more, the bolting costs more, and the extra bolt load has to be delivered with a torque wrench that can reach it.

Class 2500 stops at NPS 12

This is the constraint that usually settles the choice. B16.5 tabulates Class 2500 for NPS 1/2 through NPS 12 and no further. A large-bore line above Class 1500 leaves B16.5 entirely — it goes to API 6A, to a manufacturer's proprietary connector, or to a design-by-analysis flange under ASME Section VIII Appendix 2. The flanges are also genuinely heavy: a Class 2500 NPS 12 flange is a crane lift, not a two-person carry.

Practical selection

Class 1500 is enough when

  • Any size above NPS 12 — Class 2500 does not exist there
  • Pressures within 3705 psig at temperature
  • Where flange weight, handling and bolt tensioning access are limiting

Class 2500 is worth it when

  • Small and medium bore above the Class 1500 rating
  • High-pressure injection, test and hydraulic headers
  • Where the alternative is leaving B16.5 for a proprietary connector

Common questions

What is the highest ASME B16.5 flange class?

Class 2500, rated 6170 psig at 100 °F in Group 1.1 carbon steel. It is published from NPS 1/2 through NPS 12 only.

What comes above Class 2500?

Nothing within B16.5. Higher pressures use API 6A flanges, proprietary clamp connectors, or a flange designed under ASME Section VIII Division 1 Appendix 2.

Are Class 2500 flanges always RTJ?

Almost always in practice. Raised face Class 2500 flanges are published, but the bolt loads involved make a metal ring seal the sensible choice.

Can I use a Class 2500 flange at low pressure?

You can, and it is occasionally done for erosion or mechanical reasons, but it is expensive, heavy and usually signals that something else in the design should change.
