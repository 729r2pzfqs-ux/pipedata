Where a Class 1500 slip-on flange is used

Class 1500 is used on high-pressure injection, wellhead and power plant feed water and steam lines. Flanges in this class are heavy enough that joint make-up is normally done with controlled tightening rather than by feel.

A slip-on is an unusual choice at this class. ASME B16.5 publishes it through NPS 24 in Class 900, through NPS 2 1/2 only in Class 1500, and not at all in Class 2500. Most high-pressure specifications call for a weld neck instead.

The number 1500 is a designation and not a pressure. A Class 1500 flange in A105 carbon steel is rated 3705 psig (255.5 bar) at 100 °F, 3170 psig at 400 °F, 2840 psig at 600 °F and 2055 psig at 800 °F. In Type 304 stainless, Group 2.1, it starts at 3600 psig and still holds 2030 psig at 800 °F, so the material and the metal temperature have to be fixed before the class can be.

Across the 7 sizes published in Class 1500, the flange grows from 4.75 in (120.6 mm) across and 0.88 in (22.4 mm) thick at NPS 1/2 to 9.62 in (244.3 mm) across and 1.62 in (41.1 mm) thick at NPS 2 1/2. The bolt count goes 4 from NPS 1/2 and 8 from NPS 2, always in multiples of four so that the holes can straddle the centrelines. The largest bolt in the class is 1 in, first needed at NPS 1 1/2.

ASME B16.5 publishes the slip-on flange in Class 1500 up to NPS 2 1/2 only. The Class 1500 table runs on to NPS 24 for other flange types, but there is no slip-on flange in those sizes, so they are not listed here.

Bolt holes, spacing and torque

Bolt holes in ASME B16.5 flanges are drilled 1/8 in larger than the nominal bolt and are set to straddle the vertical and horizontal centrelines, never to sit on them. Spacing is the distance between neighbouring holes measured round the bolt circle, which shows how much room there is for a wrench or a tensioner. The torque column is a starting figure for a lubricated stud, not a joint-specific value.

Common questions

How many bolts does a Class 1500 slip-on flange use?

NPS 1/2 takes 4 × 3/4 in; NPS 3/4 takes 4 × 3/4 in; NPS 1 takes 4 × 7/8 in; NPS 1 1/4 takes 4 × 7/8 in; NPS 1 1/2 takes 4 × 1 in. Bolt count rises with size — see the table above for the full range.

What pressure is a Class 1500 flange rated for?

Class is a designation, not a pressure. A Class 1500 flange in A105 carbon steel is rated 3705 psig (255.5 bar) at 100 °F, and that rating falls as metal temperature rises. In stainless the same class starts lower at ambient but holds up far better in the heat — see the P-T rating tables.

Will a Class 1500 flange bolt to a Class 150 flange?

No. Bolt circle diameter, bolt count and bolt size all change with class, so flanges of different classes in the same NPS will not mate. The only exceptions inside B16.5 are the deliberate ones the standard calls out, such as Class 400 sharing Class 600 dimensions in NPS 1/2 through 3 1/2.
