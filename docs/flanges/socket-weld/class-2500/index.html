Class 2500 Socket Weld Flange

ASME B16.5 does not publish a socket weld flange in Class 2500.

Correction. This page used to show a dimension table. The figures in it were those of other Class 2500 flange types, and they did not describe a socket weld flange that the standard publishes. The table has been withdrawn.

The socket weld flange is published in Class 150, Class 300, Class 600 and Class 1500. In Class 2500 the flange types ASME B16.5 does publish are listed below.
