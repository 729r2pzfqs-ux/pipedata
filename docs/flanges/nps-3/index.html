Length through hub

How far the flange stands off the joint, which is what a spool drawing needs. B16.5 carries hub length for Classes 150 and 300 only; above that the hub follows the bore and varies with the schedule the flange is ordered to.

The pipe these flanges bolt to

NPS 3 pipe is 3.500 in (88.9 mm) outside diameter in every schedule, which is why one flange OD serves the whole range. Standard weight is a 0.216 in (5.5 mm) wall, giving a 3.068 in (77.9 mm) bore — the figure a weld neck flange in this size is normally bored to.

Common questions

What is the bolt circle of an NPS 3 flange?

Class 150 is 6.00 in with 4 × 5/8 in bolts; Class 300 is 6.62 in with 8 × 3/4 in bolts; Class 400 is 6.62 in with 8 × 3/4 in bolts; Class 600 is 6.62 in with 8 × 3/4 in bolts. The bolt circle grows with the class, which is why an NPS 3 flange of one class will not bolt to another.

Do all six flange types share these NPS 3 dimensions?

Yes. Flange outside diameter, thickness, bolt circle, bolt count and bolt size are set by NPS and class alone — a weld neck, slip-on, threaded, lap joint, socket weld and blind of the same size and class are dimensionally interchangeable at the bolted joint. What differs is how each attaches to the pipe.

How much bigger is a Class 2500 flange than a Class 150 in NPS 3?

12.00 in outside diameter against 7.50 in, and 2.62 in thick against 0.94 in — 2.8× the metal in the flange ring, plus heavier bolting on a wider bolt circle.
