Threaded Flange Dimensions

Tapped with an ASME B1.20.1 NPT taper thread and screwed onto matching pipe, with no welding at all. That makes it the flange for places where a hot work permit is impossible.

Strengths

  • No welding, so usable in flammable or explosive areas
  • Fast field installation with hand tools

Limitations

  • Not for cyclic, high-temperature or vibrating service — the thread loosens
  • Thread root reduces the effective wall; needs thick-wall pipe

Common questions

When should I use a threaded flange?

Low-pressure utility piping and hazardous areas where welding is banned.

What pressure classes does a threaded flange come in?

ASME B16.5 publishes the threaded flange in Class 150, Class 300, Class 400, Class 600, Class 900, Class 1500 and Class 2500, in sizes NPS 1/2 through NPS 24. Above NPS 24 large-diameter flanges are covered by ASME B16.47 instead.

Does the flange face type change these dimensions?

The flange outside diameter, bolt circle and bolting are the same whatever the face. What changes is the facing itself and the flange thickness measurement: B16.5 thickness excludes the raised face, so a Class 300 raised-face flange is 0.06 in thicker overall than the tabulated figure. Ring-type joint flanges are grooved instead and are dimensioned separately.
