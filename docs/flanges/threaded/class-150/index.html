Common questions

How many bolts does a Class 150 threaded flange use?

NPS 1/2 takes 4 × 1/2 in; NPS 3/4 takes 4 × 1/2 in; NPS 1 takes 4 × 1/2 in; NPS 1 1/4 takes 4 × 1/2 in; NPS 1 1/2 takes 4 × 1/2 in. Bolt count rises with size — see the table above for the full range.

What pressure is a Class 150 flange rated for?

Class is a designation, not a pressure. A Class 150 flange in A105 carbon steel is rated 285 psig (19.7 bar) at 100 °F, and that rating falls as metal temperature rises. In stainless the same class starts lower at ambient but holds up far better in the heat — see the P-T rating tables.

Will a Class 150 flange bolt to a Class 150 flange?

No. Bolt circle diameter, bolt count and bolt size all change with class, so flanges of different classes in the same NPS will not mate. The only exceptions inside B16.5 are the deliberate ones the standard calls out, such as Class 400 sharing Class 600 dimensions in NPS 1/2 through 3 1/2.
