Straight Cross Dimensions

An equal four-way fitting, with a straight run and two opposed branches all the same size. ASME B16.9 tabulates the straight cross in the same table as the straight tee, and the run dimension C is identical between the two — a cross is a tee with a second branch added, not a differently-dimensioned fitting.

B16.9 dimensions are a function of NPS only and do not change with schedule or wall thickness.

Same size, any schedule. Because these dimensions depend on NPS alone, a spool drawing can be dimensioned before the schedule is fixed. The wall thickness still has to be ordered to match the pipe, or the weld prep will not line up.

Not tabulated here. B16.9's cross table applies through NPS 24 only; above that size the standard tabulates tees but not crosses. Reducing crosses, where the branches are smaller than the run, are tabulated separately by size combination in B16.9 Table 9, the same way reducing tees are — read the branch dimension for your exact combination from a current copy of the standard.

Common questions

What is the centre-to-end c of an NPS 8 straight cross?

7.00 in (177.8 mm). ASME B16.9 dimensions depend on NPS only, so this figure is the same in every schedule.

Does the straight cross dimension change with wall thickness?

No. ASME B16.9 sets fitting dimensions from NPS alone. A schedule 40 and a schedule 160 fitting of the same size have identical centre-to-end dimensions — only the wall thickness and the bore differ, so the fitting still matches its pipe at the weld.

What material are straight crosss made from?

Carbon steel fittings are normally ASTM A234 WPB, matched to A106 Gr B pipe. Low-temperature service uses A420 WPL6, stainless uses A403 WP304/WP316, and chrome-moly uses A234 WP11, WP22 or WP91. See the material grade reference.
