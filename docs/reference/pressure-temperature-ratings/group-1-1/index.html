Common questions

Which materials are in ASME B16.5 Group 1.1?

A105, A216 WCB, A515 Gr 70, A516 Gr 70, A350 LF2 (as forged).

What is a Class 300 Group 1.1 flange rated at 600 °F?

570 psig (39.3 bar). At 100 °F the same flange is rated 740 psig (51.0 bar).
