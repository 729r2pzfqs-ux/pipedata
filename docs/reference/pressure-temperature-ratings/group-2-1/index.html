Common questions

Which materials are in ASME B16.5 Group 2.1?

A182 F304, A182 F316, A312 TP304, A312 TP316, A240 304/316.

What is a Class 300 Group 2.1 flange rated at 600 °F?

450 psig (31.0 bar). At 100 °F the same flange is rated 720 psig (49.6 bar).
